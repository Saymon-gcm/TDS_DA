Exercícios-8

1)
GET: serve para consultar ou buscar informações.
POST: serve para cadastrar ou criar uma nova informação.
PUT: serve para atualizar os dados de um registro.
PATCH: serve para alterar apenas uma parte dos dados.
DELETE: serve para excluir um registro

2)
O PUT atualiza o registro de forma completa, enquanto o PATCH altera somente uma informação específica.

3)
Porque o ID identifica qual usuário será excluído. No caso do exercício, o usuário é identificado pelo id=1

4)
Porque o 201 indica que um novo registro foi criado. O 200 indica apenas que a operação foi realizada com sucesso.

5)
