9)QUESTAO
Na empresa que você trabalha está sendo feito um levantamento sobre os valores dos produtos que são comercializados.

Para ajudar o setor que está fazendo esse levantamento você deve calcular e exibir o valor médio do preço dos produtos.

OBS: Mostrar o valor com dois números após o ponto.

Esquema
products
Coluna	Tipo
id (PK)	numeric
name	varchar
amount	numeric
price	numeric
 
Tabelas
products
id	name	amount	price
1	Two-doors wardrobe	100	800
2	Dining table	1000	560
3	Towel holder	10000	25.50
4	Computer desk	350	320.50
5	Chair	3000	210.64
6	Single bed	750	460
 
Exemplo de saída
price
396.10

RESPOSTA: |SELECT                          |
          |ROUND(AVG(p1.price), 2) AS price|
          |FROM products p1                |
          |INNER JOIN products p2          |
          |ON p1.id = p2.id;               |

Explicação:
|-----------------------------------------------------------------------|
|INNER JOIN une registros que possuem correspondência.                  |
|                                                                       |
|Aqui estamos ligando a tabela nela mesma (p1 com p2) pelo id.          |
|                                                                       |
|O resultado continua o mesmo porque cada produto só encontra ele mesmo.|
|                                                                       |
|AVG(p1.price) calcula a média.                                         |
|                                                                       |
|ROUND(..., 2) mantém duas casas decimais.                              |
|-----------------------------------------------------------------------|
